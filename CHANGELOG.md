# Что изменилось с момента хендоффа (CONTINUE_HERE.md)

Ниже — все правки этой сессии, по темам. Пункты со звёздочкой (*) — это
не то, что просили изначально, а баги/дыры, которые нашлись по пути и
были исправлены заодно.

## Деньги и безопасность

- Полный номер карты теперь шифруется на сервере (AES-256-GCM) и хранится
  зашифрованным. Владелец магазина может посмотреть полный номер в
  карточке заказа (кнопка-глазик) — например, для оформления возврата.
  Администратор (не владелец) видит только маску, доступа к расшифровке
  у него нет.
- *Ключ шифрования карт лежал в общей таблице настроек, и публичный
  эндпоинт настроек отдавал его вообще без авторизации — то есть ключ,
  которым расшифровываются все карты, был доступен любому посетителю
  сайта. Закрыла.
- Экспорт/импорт всей базы данных одним файлом (в настройках, только
  владелец) — для переноса между хостингами. Файл включает пользователей,
  заказы, товары и зашифрованные карты вместе с ключом шифрования.
- *И новая функция «закрыть один заказ», и старая «очистить всю базу
  заказов» падали с ошибкой 500, если у заказа было уведомление —
  внешний ключ `notifications.order_id` не давал удалить заказ без
  удаления самого уведомления. Починила оба места.
- Удаление аккаунта пользователем — теперь мягкое: данные хранятся 30
  дней, повторный вход тем же логином автоматически восстанавливает
  аккаунт. Через 30 дней данные стираются насовсем. Очистка просроченных
  аккаунтов происходит при каждом старте сервера и при каждом
  логине/регистрации (без крона — работает на любом хостинге, включая
  тот, что засыпает).
- Смена пароля (текущий/новый/повтор) в личном кабинете. «Забыли пароль»
  на странице входа — важный момент: настоящий пароль восстановить
  невозможно физически (хранится только хэш), поэтому выдаётся новый
  пароль сразу на экране — как и смена почты, это демо-режим без
  реальной отправки писем.
- Купоны: ограничение по категориям товаров, общий лимит использований,
  лимит «1 раз на пользователя». Скидка считается только с товаров
  подходящей категории, а не со всего заказа.
- Капча теперь также срабатывает при признаках VPN/прокси (каскадом
  через два бесплатных сервиса — если один недоступен, пробуется второй;
  если оба недоступны, капча не показывается, чтобы не блокировать
  живых людей). После прохождения капчи — 5 минут без повторных проверок.
- *Обнаружила рассинхрон между форматом времени JS (`toISOString()`) и
  форматом SQLite (`datetime('now')`) — в редких случаях сравнение дат
  могло работать неверно. Починила в очистке аккаунтов и в новой ленте
  активности админки.

## Админ-панель

- Уведомления о новых заказах и новых пользователях теперь показываются
  на любой странице админ-панели (не только там, где раньше была своя
  логика) — стопкой внизу слева, обновляются раз в 8 секунд.
- Заказы и товары: вместо выпадающих списков фильтр по статусу/категориям
  — чекбоксы во всплывающей панели (можно выбрать несколько сразу).
  Сортировка — по клику на заголовок столбца, с указателем направления.
- Возможность менять иконку у товара: выбор из готовых форм (29 штук)
  или загрузка своей SVG-иконки. Владелец может менять любую иконку,
  администратор — только у товаров, которые создал сам. Неиспользуемые
  загруженные иконки удаляются с диска автоматически.
- Кнопки «Заморозить» и «Заблокировать» поменяны местами.
- Убрала дубль слова «владелец» в шапке админки.
- Убрала строку «Адрес для других устройств» из обзора — осталась только
  в консоли сервера при локальном запуске.
- Настройки: соцсети теперь редактируются (префикс + ссылка, можно
  добавлять/удалять), фраза над ними, заголовок и подзаголовок главной
  страницы. Убрала поле «Название магазина» — оно и так зашито в лого
  и коде, менять его через форму было бы рассинхроном.
- Бейдж «Осталось всего N шт.» красным на карточке товара (по умолчанию
  при остатке ≤10) + чекбокс «Показывать всегда» для принудительного
  показа.

## Витрина

- Картинки на карточках товара, в корзине и на странице товара раньше
  насильно сжимались до 58–74% контейнера — теперь занимают всё место
  без обрезки.
- Поле поиска растянула от лого до иконок (раньше было ограничено
  480px) — само сжимается, когда иконок в шапке больше.
- Подсказки при вводе в поиск (стрелки/Enter/клик по варианту).
- Крестик или стирание текста в поиске сразу сбрасывает фильтр по
  запросу, не трогая фильтр по категории/цене.
- Тема оформления по умолчанию берётся из системных настроек браузера,
  если раньше не переключали вручную.
- Подсказки (title) на иконках шапки — тема, уведомления, избранное,
  корзина, кабинет, поиск, админ-панель.
- Купон переехал под блок оплаты на чекауте.
- Сохранённый адрес — подставляется на чекауте из прошлого заказа,
  можно поменять.
- Рекомендации на странице товара: «С этим товаром часто берут» (по
  реальным совместным покупкам), «Может вам понравиться» (та же
  категория), «Вы недавно смотрели» (локально в браузере, до 8 товаров).
- Постоянные объявления: крестик теперь честно прижат к правому краю
  по центру высоты полосы, а не рядом с текстом по центру экрана.
- Панель уведомлений на мобильном была `position: absolute` от кнопки
  и могла уехать за экран — теперь `position: fixed` с отступами от
  краёв.
- Правовая информация в футере: новая страница `/legal.html` (закон о
  защите прав потребителей, правила продажи, контакты Роспотребнадзора)
  + ссылка на неё и на политику конфиденциальности.
- *Текст в политике конфиденциальности всё ещё врал, что номер карты
  «нигде не сохраняется» — переписала честно, раз это больше не так.
- Ссылка «Назад» на странице политики теперь смотрит на referrer: из
  регистрации — в регистрацию, с сайта — на главную.
- Страницы входа/регистрации редиректят на главную, если уже залогинен.
- Форма входа запоминает последний email и подставляет его при
  следующем заходе (сессия и так держится 30 дней без повторного входа).
- Гарантированный отступ между колонками сумм в заказе (было — текст
  слипался, если что-то схлопывало flex).
- Убрала подсказку с тестовым email со страницы входа (осталась в
  README и в списке пользователей админки).
- Фавикон — сделала из фирменного знака сороки, подключила на все
  страницы.

## Технические / инфраструктура

- Сервер сам находит свободный порт, если основной занят (пробует
  следующие 10 подряд), при полном отказе — спрашивает порт в консоли.
  Переменная `PORT` от хостинга не трогается.
- Idle-пинг: если 12.5 минут никто не обращался к серверу, он сам
  пингует себя (держит бесплатный засыпающий хостинг живым) и на
  публичном сайте показывает промо-баннер с купоном FREE — стакается
  с системными объявлениями, не дублируется, пока не закрыт.
- `restart-loop.bat` — серверное окно теперь само перезапускается после
  чистого выхода процесса (нужно для импорта миграции и просто для
  устойчивости).
- IP для локальной сети теперь исключает APIPA-адреса (169.254.x.x).
- Из архива/репозитория исключены автогенерируемые иконки товаров
  (~1.2MB, пересоздаются сами при первом запуске сервера).
- Добавлены `Procfile` и `railway.json` — заготовки для деплоя на другие
  хостинги, `render.yaml` не тронут. В README — честная секция про
  другие бесплатные варианты (без завышенных обещаний, т.к. источники
  по теме сами друг другу противоречат).
- Комментарии в коде — только там, где были и раньше; новый код без
  комментариев, как просил.

## Не доделано / нужна проверка руками

- **Мобильная вёрстка** — не могу визуально проверить без реального
  браузера на телефоне. Логика (адаптивные брейкпоинты, фикс панели
  уведомлений) на месте, но глазами не смотрела.
- **VPN-детект** — сама проверка на прокси не тестировалась «вживую» с
  реальным подозрительным IP (только логика и safe-fail при недоступности
  сервисов). У бесплатных антипрокси-сервисов небольшие лимиты запросов
  в месяц — при большом трафике проверка может тихо переставать
  работать (это ожидаемо, не баг).
- Реальный платёжный шлюз и настоящая отправка почты — осознанно вне
  скоупа учебного проекта (как и раньше, по хендоффу).
