# Интернет-магазин «Сорока»

Учебный проект: полноценный интернет-магазин (фронтенд + бэкенд + база данных)
по техническому заданию колледжа. Ниша - «всего понемногу» (одежда,
электроника, продукты, дом, книги, красота).

## Стек

- **Бэкенд:** Node.js + Express + SQLite (better-sqlite3)
- **Авторизация:** JWT в httpOnly-cookie, пароли - bcrypt
- **Фронтенд:** обычные HTML/CSS/JS-страницы (без сборщика), запросы к API через `fetch`
- **Картинки товаров:** фирменные SVG-заглушки, свои для каждого товара -
  генерируются локальным скриптом, внешние источники не используются
- **Живые обновления:** лёгкий поллинг (опрос сервера раз в несколько секунд)
  для корзины/избранного/уведомлений на сайте и для заказов/пользователей/
  товаров в админ-панели - без сокетов, просто периодические запросы

## Установка и запуск

### Windows - самый простой способ

Дважды кликните **`start.bat`** обычным способом. Никаких прав
администратора не требуется и ничего не устанавливается в систему -
скрипт скачивает **портативную** версию Node.js в папку `node-portable`
рядом с проектом и использует её напрямую. Дальше скрипт сам:
- установит зависимости проекта при первом запуске;
- один раз наполнит базу данных тестовыми товарами;
- запустит сервер и откроет магазин в браузере.

При повторных запусках `start.bat` пропускает уже сделанные шаги и просто
стартует сервер. Если что-то пойдёт не так, рядом со `start.bat` появится
файл **`start-log.txt`** с подробностями.

### Вручную (Windows/macOS/Linux, если уже есть Node.js)

```bash
npm install
npm run seed     # один раз - создаёт базу и наполняет её товарами
npm start         # запускает сервер на http://localhost:3000
```

При старте сервер также печатает адрес для других устройств в той же
локальной сети (телефон и т.п.), например `http://192.168.0.37:3000` -
удобно, если `localhost` не открывается на каком-то устройстве.

Если база данных ещё не создана (файл `server/data.sqlite` отсутствует),
сервер **сам** наполнит её тестовыми данными при первом запуске - это
особенно важно при деплое на хостинг, где некому вручную вызвать `npm run seed`.

## Роли пользователей

- **Владелец** видит всё, что видит администратор, плюс управляет ролями
  других пользователей, купонами, объявлениями на сайте, может
  замораживать/удалять аккаунты, очищать базу заказов и видит полные
  email и номер карты в заказах.
- **Администратор** управляет товарами, категориями, заказами, может
  отвечать на отзывы, блокировать пользователей и редактировать их
  профиль (имя, email), но не может назначать роли, замораживать
  аккаунты или увидеть email и номер карты целиком - только в
  маскированном виде.
- **Покупатель** - обычный зарегистрированный посетитель магазина.

## Админ-панель

Доступна по прямому адресу **/admin** - ссылки на неё в обычной навигации
нет. Доступ проверяется на бэкенде: обычный покупатель получит страницу
403. Когда на сайт заходит администратор или владелец, в шапке сайта
появляется иконка молотка со ссылкой на панель.

Разделы: Обзор (живая статистика), Товары (сортировка, фильтр по категории),
Категории, Заказы (сортировка, клик по строке открывает полную карточку
заказа с составом, адресом и маскированным номером карты), Пользователи
(роли, блокировка, заморозка), Купоны и Объявления (только у владельца),
Настройки магазина.

## Капча / проверка на бота

`public/captcha.html` - экран проверки «я не робот» в фирменном стиле, с
анимированным 3D-фоном на three.js.
Тема капчи переключается по времени суток посетителя: светлая с 9:00 до
17:00, тёмная - в остальное время.

Сервер (`server/index.js`) считает GET-запросы к страницам с одного IP за
скользящее окно 12 секунд; если их больше 4 - отправляет на `/captcha.html`
вместо запрошенной страницы. Так же проверяется IP на признаки VPN/прокси
(proxycheck.io и ip-api.com, с эвристикой по названию хостинг-провайдера).
Кука подтверждения капчи сессионная - закрыли браузер, при следующем заходе
капча покажется снова. Это демонстрационная, а не промышленная антибот-
защита. После нажатия на галочку посетитель возвращается туда, куда шёл
изначально (параметр `?next=`).

## Структура проекта

```
server/            Backend (Express)
  index.js          точка входа, роуты, статика, антибот-редирект, автосидирование
  db.js             схема SQLite + защитные миграции
  seed.js           наполнение тестовыми данными (экспортирует функцию run)
  gen-images.js      генератор SVG-иконок товаров (у каждого товара своя)
  middleware/auth.js JWT-проверка, requireAuth/requireAdmin/requireOwner, заморозка
  routes/            auth, categories, products, cart, favorites, orders,
                      reviews, notifications, announcements, coupons,
                      settings, admin
public/             Витрина (HTML/CSS/JS)
  index.html, catalog.html, product.html, cart.html,
  checkout.html, account.html, login.html, register.html,
  privacy.html, captcha.html, 403.html, 404.html
  css/style.css      дизайн-система (светлая/тёмная тема)
  js/                api.js, main.js (шапка/тема/уведомления/объявления),
                      three_scene.js (фон капчи), логика страниц
  images/captcha/    картинки для фона капчи (светлая/тёмная тема)
admin_public/       Админ-панель (SPA на хеш-роутинге)
  index.html, css/admin.css, js/app.js + разделы
render.yaml         Render Blueprint для деплоя одним кликом
start.bat           Установка и запуск на Windows одним кликом
```

## Функционал по разделам ТЗ

- **Система авторизации** - регистрация с согласием на обработку данных,
  вход, выход, сессия на JWT-cookie, смена имени (раз в 3 суток) и почты
  (с кодом подтверждения), удаление аккаунта
- **Главная** - популярные товары, категории, поиск (регистронезависимый,
  включая кириллицу)
- **Каталог** - фильтр по цене, сортировка, пагинация, хлебные крошки с
  категорией
- **Карточка товара** - галерея, цена/старая цена, индикатор наличия,
  отзывы со звёздами, опцией «анонимно» и ответом администрации
- **Корзина** - количество прямо на карточке товара, понятный формат
  строки (цена × количество)
- **Оформление заказа** - самовывоз (с выбором пункта выдачи) по умолчанию,
  курьер, почта; стоимость доставки; купон на скидку; демо-шаблоны оплаты
  (карта с маской номера, СБП)
- **Личный кабинет** - профиль сверху, избранное, мои отзывы, история
  заказов с живым обновлением статуса, уведомления, тёмная тема, опасная
  зона с удалением аккаунта
- **Админ-панель** - товары/категории/заказы/пользователи/купоны/
  объявления/настройки магазина, роль «владелец» с расширенными правами
